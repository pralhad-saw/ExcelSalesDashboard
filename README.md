# 📊 Excel Sales Dashboard

## 📌 Project Overview

This project presents an interactive **Sales Dashboard** created using Microsoft Excel to analyze sales performance, profitability, and business trends.

The dashboard transforms raw sales data into meaningful insights through interactive visualizations.

---

## 🛠️ Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

---

## 📈 Dashboard Features

- **Total Sales:** Overall revenue generated.
- **Total Profit:** Total profit earned.
- **Monthly Sales Analysis:** Track sales trends over time.
- **Category-wise Sales:** Analyze product category performance.
- **Regional Sales Performance:** Compare sales across different regions.
- **Interactive Filters:** Explore data using Excel slicers.
